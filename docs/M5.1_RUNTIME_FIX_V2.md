# M5.1 Runtime Fix Notes

This release keeps the documented npm-only runtime path. Historical runtime notes remain unchanged; current Windows native diagnostics execute the Electron binary directly (`shell:false`) and invoke the `.cmd` rebuild shim only when a native rebuild is required.

# M5.1 Runtime Fix V2

## Windows/npm startup

`npm install` deliberately does not run `electron-rebuild`. This avoids long install-time native rebuilds. `npm run dev` performs a fast Electron-native compatibility check and rebuilds only `better-sqlite3` when it is missing or incompatible.

## Electron desktop window

The backend dev script uses `electron .`, so Electron resolves `main: dist/main.js` from `app/backend/package.json`. The JARVIS window is a real Electron desktop window. Vite at `http://127.0.0.1:5173` is only the internal renderer server.

The main window is initialized before the database/native subsystem finishes. The renderer retries IPC while backend startup continues, so a slow subsystem should not prevent the HUD from appearing.

## Model defaults

Gemini default is `gemini-2.5-flash`. Provider model IDs remain configurable. API keys are never placed in frontend source.
